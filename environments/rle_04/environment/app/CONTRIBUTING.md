# Reservation service releases

Studio tickets ship through the studio adapter and the replay dispatcher. The platform team supplies the shared library, the allocation catalog and the Archive adapter as a versioned distribution. Their approved contents are listed in config/platform-release.lock. A change to that distribution schedules a separate platform release and requires a platform ticket. A studio allocation ticket authorizes the studio release only.

The packaged renewal API targets the default desk. A service with a specialized admission rule can compose the existing ledger lookup and its own booking adapter for renewals. The compatibility contract includes missing or cancelled predecessor IDs, immutable tenant identity and a replacement unit count for the new period.
